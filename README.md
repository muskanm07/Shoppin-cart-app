# Shopping Cart App

A simple Shopping Cart application built using React.js.  
This project demonstrates React fundamentals like component-based architecture, state management using `useState`, event handling, and dynamic UI updates.

## Features

- Add items to cart
- Remove items from cart
- Real-time cart count updates
- Dynamic rendering using React
- Simple and responsive UI

## Tech Stack

- React.js
- JavaScript (ES6+)
- HTML5
- CSS3
- Vite

## Concepts Used

- Functional Components
- Props
- useState Hook
- Event Handling
- Conditional Rendering
- Array Mapping

## Installation

Clone the repository:

```bash
git clone <your-repository-link>
```
Navigate to the project folder:
```
cd shopping-cart-app
```
Install dependencies:
```
npm install
```
Start the development server:
```
npm run dev
```
